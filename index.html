Step 1

온보딩 에이전트와 대화해보기

Gobi가 나다운 결과를 만들 수 있도록 관심사, 선호 기준, 글쓰기 스타일을 먼저 남깁니다.

기능 / 역할

G5O는 5분 온보딩 에이전트입니다. 관심사, 선호 기준, 글쓰기 스타일을 질문으로 끌어내 Context에 남깁니다.

해야 할 일
  • 온보딩 에이전트를 선택합니다
  • 짧게 자기소개를 합니다
  • 요즘 관심사와 최근 경험을 말합니다
  • 글로 쓸 때 원하는 톤과 스타일을 말합니다
결과 / 확인
  • Context/interests.md: 관심사와 맥락
  • Context/preferences.md: 좋아하는 기준과 싫어하는 기준
  • Context/styles.md: 글쓰기 스타일과 어체

“Gobi 5-Minute Onboarding (G5O)” 에이전트 선택

실행 / 프롬프트

“온보딩을 시작해주세요.”

Step 2

대화로 생각 기록하기

Capture로 흘러가는 대화와 경험을 나중에 쓸 수 있는 재료로 남깁니다.

기능 / 역할

Capture는 흘러가는 대화를 나중에 에이전트가 읽을 수 있는 기록으로 바꿉니다. 미팅, 일기쓰기, 생각 정리 같은 상황에서 켜두면, 그 맥락이 글쓰기·정리·확장 같은 다양한 작업의 재료가 됩니다.

이렇게 말해보세요 — 대화 주제 · 시작 문장 예시
  • "요즘 어떤 일/주제에 가장 관심이 많으세요?"
  • "최근에 써본 AI 도구나 워크플로우가 있나요?"
  • "바이브 코딩으로 풀어본 가장 재미있었던 문제는?"
  • "개발자로서 요즘 자주 떠올리는 질문은 뭐예요?"
  • "요즘 가장 깊게 파고들고 싶은 주제는?"
  • "이번 주에 새로 시도해보고 싶은 게 있나요?"

시작 문장 예: “안녕하세요. 저는 ___이고, 요즘 ___에 관심이 있어요.” → “왜 그 주제에 관심이 생겼는지 이야기해보면요…”

해야 할 일
  • Capture를 켜고 대화/생각 말하기 시작하기
  • 함께할 사람이 있으면 인사하고 질문하기, 없으면 혼자 생각을 소리 내어 말하기
  • 위 예시 중 하나를 골라 자연스럽게 이어가기
결과 / 확인
  • Capture Stop
  • History 또는 Captures 확인
  • 방금 대화가 기록으로 남았는지 보기
Step 3

인터넷에서 정보 수집하고 확장하기

내 관심사를 바탕으로 외부 정보를 수집하고, 이후 생각 정리의 재료를 확장합니다.

기능 / 역할

DRB는 Daily Research Briefing입니다. Context의 관심사와 선호를 읽고 최신 자료를 찾아 브리핑합니다.

해야 할 일
  • 웹 링크나 이미지를 지식으로 수집합니다
  • DRB 자동화를 셋업합니다
  • DRB를 one-time으로 실행합니다
결과 / 확인
  • DRB가 Context의 관심사와 선호를 읽습니다
  • 최신 자료가 Ingest/Research에 브리핑으로 정리됩니다
실행 / 프롬프트

“DRB를 실행해주세요.”

Step 4

에이전트와 생각 정리하기

내 볼트와 리서치 내용을 바탕으로 에이전트와 대화하며 관점을 정리합니다.

기능 / 역할

DTA는 Deep Thinking Assistant입니다. 답을 주입하지 않고 한 번에 한 질문씩 던져 내 관점을 끌어냅니다.

해야 할 일
  • DTA와 대화를 시작합니다
  • 오늘 리서치한 내용에 대한 내 생각을 말합니다
  • 시간이 끝나면 정리 요청으로 마무리합니다
결과 / 확인
  • DTA가 답을 주입하지 않고 질문으로 생각을 끌어냅니다
  • 정리된 내용은 다음 글쓰기 단계의 재료가 됩니다

“Deep Thinking Assistant (DTA)” 에이전트 선택

실행 / 프롬프트

“오늘 리서치한 내용을 읽고 이런 생각이 들었습니다…” 마무리: “이쯤에서 생각을 정리해주세요.”

Step 5

정리된 생각으로 글 쓰기

정리된 생각을 글 초안으로 만들고, Gobi Space에 공유할 수 있는 형태로 다듬습니다.

기능 / 역할

/writeup은 직전 대화에서 나온 내 표현과 통찰을 글 초안으로 만들고, 저장이나 게시 단계로 이어주는 커맨드입니다.

해야 할 일
  • DTA 대화가 끝난 뒤 /writeup을 호출합니다
  • 제안된 초안 중 원하는 톤을 고릅니다
  • 저장할지, Gobi Space에 게시할지 선택합니다
결과 / 확인
  • 사용자 표현과 통찰을 살린 글 초안이 생깁니다
  • 선택에 따라 Articles에 저장되거나 Gobi Space에 게시됩니다
실행 / 프롬프트

“/writeup”

Step 6

나만의 홈페이지 만들기

내 관심사, 글쓰기 스타일, 최근 글이 드러나는 공개 대문을 만듭니다.

기능 / 역할

create-gobi-homepage는 내 Brain homepage를 만들어 Gobi Space에서 나를 설명하는 공개 대문을 구성하는 스킬입니다.

해야 할 일
  • create-gobi-homepage 스킬을 실행합니다
  • 내 관심사와 글쓰기 스타일이 드러나게 요청합니다
  • 생성된 홈페이지를 확인합니다
결과 / 확인
  • 내 브레인의 공개 대문이 생깁니다
  • 최근 글과 업데이트가 노출됩니다
  • Gobi Space에서 나를 이해하는 입구가 됩니다
실행 / 프롬프트

“홈페이지를 만들어주세요. 내 관심사와 글쓰기 스타일이 드러나게 구성해주세요.”

Step 7

사람과 사람 연결하기

Gobi Space에서 나와 관심사와 성향이 맞는 사람을 찾아 대화로 이어갑니다.

기능 / 역할

Gobi Space는 공유된 생각과 프로필을 바탕으로 관심사와 성향이 비슷한 사람을 찾는 공간입니다.

해야 할 일
  • Gobi Space에 올라온 포스트를 확인합니다
  • 나와 관심사와 성향이 비슷한 사람을 찾습니다
  • 마음에 드는 사람에게 실제로 대화를 시작합니다
결과 / 확인
  • 생각을 공유했기 때문에 사람 연결이 가능해집니다
  • Gobi Space는 포스트 목록이 아니라 관심사 기반 연결 공간이 됩니다
실행 / 프롬프트

“Gobi Space에 글을 쓴 사람 중 나와 관심사와 성향이 비슷한 사람을 3명 찾아주세요.” “내가 속한 스페이스에 올라온 포스트를 확인해보고 저와 잘 맞을 것 같은 사람을 찾아주세요.”

생각은 혼자 쌓이지만,
관점은 사람과 연결될 때 넓어집니다.
