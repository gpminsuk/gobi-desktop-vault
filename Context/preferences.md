## 에이전트 사용 가이드

### 읽기 (READ)
- **DRB**: "소스 선호"의 선호/회피 도메인을 검색 필터로 적용
- **CEA**: "소스 선호" 따라 검색 우선순위/필터 조절
- **DTA/writeup**: "선호 / 비선호 기준"을 참조해 사용자 관점에 맞는 내용 제안

### 쓰기 / 업데이트 (WRITE / UPDATE)
- **G5O**: 온보딩에서 수집한 선호 기준과 소스 유형을 각 섹션에 반영
- **유저 직접 명령**: "선호 변경: <항목> = <값>" 명시 요청 시 업데이트

### 충돌 방지
- 변경 시 업데이트 로그에 이전 값과 새 값 함께 기록
- frontmatter `created` 는 건드리지 않는다
