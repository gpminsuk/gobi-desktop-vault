## Summary

유저의 핵심 선호를 한두 줄로 요약. 에이전트는 새 작업 시작 시 본 파일을 가볍게 훑는다.

> _(온보딩 또는 명시적 변경 요청에서 업데이트됨. 사용자 직접 편집도 가능.)_

## 콘텐츠 형식 (Content Format)

- **응답 길이**: short (1-3문장) | medium (1-2단락) | long (상세) — _기본: medium_
- **요약 vs 전문**: summary-first (핵심 먼저) | full (긴 글 그대로) — _기본: summary-first_
- **스타일**: bullet | prose | mixed — _기본: mixed_
- **다이어그램**: mermaid | ascii | 안 씀 — _기본: mermaid_
- **이모지**: 사용 | 최소 | 안 씀 — _기본: 최소_

## 알림 / 빈도 (Notifications & Cadence)

- **DRB 시각**: HH:MM (Seattle 기준) — _기본: 매일 아침 7시_
- **DRB 토픽 수**: N (1-10) — _기본: 5_
- **DRB 검색 깊이**: standard | deep — _기본: standard_
- **DRB lookback**: N일 (1-30) — _기본: 7_
- **DRB 음성 요약 포함**: yes | no — _기본: no_
- **GDR 시각**: HH:MM — _기본: 매일 저녁 9시_

## 언어 / 톤 (Language & Tone)

- **주 언어**: `.gobi/settings.yaml`의 `primaryLanguage` 따름 (현재: ko)
- **존댓말 / 반말**: 존댓말 | 반말 — _기본: 존댓말_
- **격식**: casual | professional | balanced — _기본: balanced_

## 소스 선호 (Source Preferences)

- **선호 소스 유형**: 학술 | 산업 뉴스 | 블로그 | 기술 문서 — _기본: 균등_
- **선호 도메인** (DRB/CAE가 우선 검색):
  - _없음 — 자유롭게 검색_
- **회피 도메인** (자동 필터):
  - _없음_

## 작업 흐름 (Workflow)

- **자동 실행 동의**: low (모든 단계 확인) | medium (비파괴 자동, 파일 변경만 확인) | high (모두 자동) — _기본: medium_
- **DTA 라운드 수**: N (3-7) — _기본: 5_
- **CAE 파일 자동 열기**: yes | no — _기본: no_

## 에이전트 사용 가이드

### 읽기 (READ)
- **DRB**: Step 0에서 본 파일 읽고 "알림 / 빈도", "소스 선호", "언어 / 톤", "콘텐츠 형식" 적용
- **CAE**: 출력 시 "콘텐츠 형식" 따라 요약 길이/스타일 조절; "소스 선호" 따라 검색 우선순위/필터
- **DTA**: "DTA 라운드 수" 따라 PROBE 단계 종료 시점 조절; "콘텐츠 형식" 따라 글 길이 조절
- **RVA**: 모든 응답 시 "콘텐츠 형식" (응답 길이, 이모지) + "언어 / 톤" 참조

### 쓰기 / 업데이트 (WRITE / UPDATE)
- **gobi-onboarding**: 1단계에서 사용자가 명시적으로 언급한 선호 (예: "짧게 답해줘") 저장
- **DTA / RVA**: 사용자가 대화 중 "다음부터는 ~ 해줘" 형식으로 요청하면 즉시 본 파일 업데이트 + 확인 ("선호로 저장했어요. 다음부터 적용돼요.")
- **유저 직접 명령**: "선호 변경: <항목> = <값>" 명시 요청 시 업데이트

### 충돌 방지
- 변경 시 업데이트 로그에 이전 값과 새 값 함께 기록 (롤백 가능하도록)
- frontmatter `created` 는 건드리지 않는다 (생성 시각 보존)
- `.gobi/settings.yaml`의 값과 충돌하면 settings.yaml이 우선 (런타임 설정)
- 사용자가 명시적으로 "기본으로 되돌려" 라고 하면 해당 항목을 _기본: ..._ 으로 리셋
