## 에이전트 사용 가이드

### 읽기 (READ)
- **writeup**: "글쓰기 스타일"을 참조해 초안의 포맷·톤·길이 결정
- **DTA**: "언어 / 톤"의 어체를 따라 답변 스타일 조정

### 쓰기 / 업데이트 (WRITE / UPDATE)
- **G5O**: 온보딩에서 수집한 글쓰기 스타일을 "글쓰기 스타일" 섹션에 반영
- **유저 직접 명령**: "스타일 변경: <항목> = <값>" 명시 요청 시 업데이트

### 충돌 방지
- 변경 시 업데이트 로그에 이전 값과 새 값 함께 기록
- frontmatter `created` 는 건드리지 않는다
