## 에이전트 사용 가이드

### 읽기 (READ)
- **DRB**: Step 1에서 `Articles/` 최근 수정 파일과 함께 본 파일의 "주요 관심 분야"와 "현재 학습 중"을 시드 토픽으로 사용
- **CAE (TOPIC mode)**: 유저가 모호한 주제만 줬을 때 (예: "AI") 본 파일에서 더 구체적인 키워드 보강
- **DTA (SETUP)**: 시드가 없을 때 seed 후보를 본 파일의 "주요 관심 분야"에서 추출
- **gobi-onboarding (2-1)**: 시드 글 자동 생성 시 본 파일의 관심사 반영

### 쓰기 / 업데이트 (WRITE / UPDATE)
- **gobi-onboarding (1-1, BBG/BBF)**: 프로필 수집 단계에서 확보한 관심 분야를 "주요 관심 분야" 섹션에 추가
- **DTA (SYNTHESIZE)**: 글 작성 직후, 글의 주제 태그가 본 파일에 없으면 "부수 관심 분야"로 자동 추가 제안 (AskUserQuestion으로 확인)
- **유저 직접 명령**: "관심사 추가/제거 — XXX" 같은 명시적 요청 시 해당 섹션 업데이트 + 업데이트 로그에 한 줄 추가

### 충돌 방지
- 동일 항목을 Primary와 Secondary 양쪽에 두지 않는다 (한쪽으로만)
- "관심 해제"에 있는 항목은 다른 섹션에서 제거한다
- 업데이트 시 frontmatter의 `created`는 건드리지 않고, 업데이트 로그에만 기록
